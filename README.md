🧠 ML Internship Assignments & Project – VOIS
Welcome to the repository for the Machine Learning Internship Assignments & Projects completed during my internship with VOIS. This repository contains a variety of supervised learning models and practical ML applications using Python, pandas, scikit-learn, TensorFlow, and data visualization tools like matplotlib and seaborn.

📌 Contents Overview
1️⃣ vios1.py – Iris & Salary Prediction
Model Used: Decision Tree Classifier
Dataset: Iris dataset & Salary dataset
Key Metrics: Accuracy, Confusion Matrix, Classification Report
Extras: Simple Linear Regression to predict salary based on years of experience.

2️⃣ vois_2.py – Climate Data Analysis
Dataset: temperatures.csv
Tasks:
Exploratory data analysis with seaborn and matplotlib.
Linear regression to predict February temperatures based on January.
Correlation heatmaps.
Metrics Evaluated: MAE, MSE, RMSE, Precision, Recall, F1 Score

3️⃣ vois_3.py – Graduate Admission Predictor
Dataset: Graduate Admission dataset
Model: Decision Tree Classifier (Gini & Entropy)
Target: Predict admission (1 if chance of admit ≥ 0.9, else 0)
Features: GRE, TOEFL, CGPA, SOP, LOR, etc.
Output: Visualized decision trees (admission.png & admission1.png)
Goal: Understand tree-based classification and overfitting/underfitting by varying depth.

4️⃣ vois4.py – CIFAR-10 Image Classification
Framework: TensorFlow (Keras)
Dataset: CIFAR-10 (Images of 10 object classes like cat, dog, airplane, etc.)
Model: Artificial Neural Network (ANN)
Architecture:
Flatten layer
Two Dense layers with ReLU (2048, 1024 neurons)
Final Dense layer with Softmax (10 outputs)
Training: 10 epochs with accuracy monitoring on validation set

5️⃣ vois_project.py – Diabetes Detection Project
Dataset: diabetes.csv
Models Used:
Random Forest Classifier
Logistic Regression
Steps:
Data Preprocessing and Scaling
Model Training and Evaluation
Confusion Matrix Visualization for both models
Goal: Predict diabetes outcome based on medical attributes like BMI, Glucose, Age, etc.
Evaluation Metrics: Accuracy Score, Confusion Matrix
